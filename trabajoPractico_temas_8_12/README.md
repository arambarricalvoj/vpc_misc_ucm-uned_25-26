``proyecto.ipynb`` contiene el proyecto completo.

``gen_roi.py`` es el script para generar la región de interés. Esta se guarda en ``roi.npy``.

El directorio ``M-30-HD`` contiene el dataset utilizado, ``mog2/`` los fotogramas obtenidos tras la sustracción del fondo y ``tracking/`` los fotogramas con el seguimiento de vehículos superpuesto.

Las dependencias necesarias se recogen en ``requirements.txt``.
